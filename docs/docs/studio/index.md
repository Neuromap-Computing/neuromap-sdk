# Neuromap Studio

!!! info "Coming soon"
    The Studio documentation is still being written. This section will cover
    how to use Neuromap Studio to design, train, and deploy models without
    leaving the browser.

Neuromap Studio is the visual workspace for building neuromorphic models on
top of the [Neuromap SDK](../index.md). Where the SDK gives you a
code-first workflow, Studio wraps the same pipeline — chip spec, network,
trainer, exporter — in an interactive UI.

## What this section will cover

- **Getting started** — creating a workspace and your first project.
- **Designing networks** — building chip-aware networks visually.
- **Training runs** — launching, monitoring, and comparing training runs.
- **Exporting** — producing `.nmap` hardware bundles from Studio.

In the meantime, the [SDK docs](../index.md) describe the underlying model
that Studio is built on.
